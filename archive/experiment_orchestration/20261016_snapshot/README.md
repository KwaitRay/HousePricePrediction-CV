# 近期运行编排与独立审计源码快照

这些文件原样复制自本地 `.local/`，用于追溯实验登记、独立审计、数值诊断和暂停操作。`manifest.json` 保存原路径及SHA256；未修改源码，因此旧审计文件中的源码哈希仍可核对。

这是历史快照，不是自动任务入口。部分脚本绑定旧运行ID、绝对路径或已存在产物，不能直接从归档目录执行。需要回放时，先按manifest还原到原路径，核对原输入与源码哈希；已完成阶段不能盲目重复。第40块提取按用户要求暂停，续跑适配尚未实现，必须另获恢复指令。

可维护实现见 `scripts/experiments/`；数据、模型权重、特征块、逐图预测均不在此快照中。原5篇设计文档另存 `archive/design_history/20261014_consolidation/`。
