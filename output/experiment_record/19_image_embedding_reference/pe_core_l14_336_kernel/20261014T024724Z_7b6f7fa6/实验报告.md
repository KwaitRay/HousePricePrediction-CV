# PE-Core-L14-336：冻结视觉特征

使用官方通用视觉权重，保留注意力池化与学习到的 1024 维输出投影。训练侧分组 CV 选择 gamma=1、alpha=1，OOF MSE **62190.88823**。固定验证 MSE **61825.74650**，MAE **178.20638**，高价组 MSE **282032.89245**。

单模型接近 SigLIP2 距离核，但训练侧联合融合学习到约 **52.09%** 权重。与 NaFlex、监督距离核的互补性比单独验证名次更有价值：预先登记的融合验证 MSE 为 **57982.72726**。详见[联合融合报告](../../../15_fixed_ensembles/encoder_family_oof_fusion/20261014T012302Z_b883fad1/实验报告.md)。

首次运行在特征提取前因 `safetensors.load_file` 导入路径错误失败；改用 `safetensors.torch.load_file` 后在新目录完成提取与核回归。失败运行保留，未修改权重、数据划分、训练目标或选参协议，也未复用未验证的部分特征。

模型来源、预处理与全部训练侧候选见 [registration.json](registration.json)、[training_cv.csv](training_cv.csv)。仅使用图像塔与提供的训练标签，未使用 MLLM、额外 SoCal 数据或测试标签。本模型尚无公榜反馈。
