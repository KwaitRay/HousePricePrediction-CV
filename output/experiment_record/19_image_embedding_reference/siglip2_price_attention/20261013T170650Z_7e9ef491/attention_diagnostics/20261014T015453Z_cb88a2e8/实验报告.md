# 价格残差注意力诊断

选择 12 张固定规则的验证案例，逐例复现已保存预测后，展示四个注意力头及残差分支 token 梯度乘激活。原始全图始终保留；名义 patch 网格按真实预处理映射回原图，未被 14px 卷积覆盖的底部和右侧 6px 边界不着色。

所有案例共用色标。敏感度图仅针对新增的价格残差分支，计算时缓存的核回归基线保持常量，因此不是完整价格模型的归因。最后层 token 包含全局上下文，梯度乘激活是一阶敏感度近似，不是独立局部像素贡献；注意力也不是泳池/建筑检测或因果证据。

案例包括较好和固定随机样本，既有价格仅用于误差描述及诊断样本选择，不用于新训练、校准或方法选择。价格单位为千美元；raw prediction 复现容差 rtol=1e-6、atol=1e-3，用于 CPU/GPU 浮点差异。原图与图像衍生诊断图保存在 .local，不打包原始课程图片。
