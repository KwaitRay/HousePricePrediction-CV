# 冻结 SigLIP2 全图特征上的价格残差注意力

## 结果

训练侧 GroupKFold 选择 **15 轮、残差系数 0.25**。原价未加权 OOF MSE 为 **64948.02373**，相同固定核基线为 65804.97970。方法固定后重训并评估原有 1601 条验证记录：

| 指标 | 原 SigLIP2 单视图核 | 价格残差注意力 |
| --- | ---: | ---: |
| 验证 MSE | 62189.37 | 61810.30 |
| 验证 MAE | 180.98 | 180.13 |
| 高价组 MSE（>1300 千美元） | 285929.78 | 278645.67 |

价格分支带来小幅总体改善及高价组改善，仍未达到 50000。它没有超过当前已记录的融合方案；本实验也尚无公榜反馈。全量开发训练记录的拟合 MSE 为 31077.46，仅用于训练诊断，不是泛化成绩。

## 方法与核验

视觉编码器冻结，使用官方全图预处理产生 729×1152 的最后层 patch token。四个价格监督注意力头分别池化全图 token，再用小回归器预测固定 RBF 基线的残差；最终按预先训练侧选择的系数叠加，保留全图基线。

每个外部拟合折内重新计算内层分组 OOF 基线残差，外部留出价格不进入该折的残差目标。外部训练 OOF 比较轮数 5/15/30 与系数 0/0.25/0.5/1；零残差系数复现原有全部训练 OOF。原始核超参数此前已经选择，本次指标仍不视为完全嵌套的无偏模型选择估计。完整候选见 [training_cv.csv](training_cv.csv)，配置见 [registration.json](registration.json)。

## 案例诊断

十二个案例包含高价最大低估、较好的高价预测、低价最大高估及固定随机案例。逐例 CPU 预测复现通过，最大差约 2.7e-5 千美元。梯度乘激活另用逐步缩小扰动的中心差分核验；最强 token 的解析值 -28.37953，与步长 0.001 的差分 -28.37658 一致。初次固定 0.01 步长核验的失败记录保留，未重新训练或修改价格模型。

图像、四头权重和敏感度网格保存于 .local。数值原图与采用统一对数注意力色标的补充展示保持字节一致。见[诊断报告](attention_diagnostics/20261014T020112Z_2d5b7ae4/实验报告.md)，完整复现记录见[原数值诊断](attention_diagnostics/20261014T015453Z_cb88a2e8/cases.json)。

例如高价低估案例 2138.jpg 的真实价格为 1995 千美元，核基线 663.81，最终预测 658.98；残差仅 -4.83。较好案例 5071.jpg 的真实价格为 1695，核基线 1674.25，最终 1722.52；残差 +48.27。新增分支并未修复最难案例的大幅基线误差。

注意力头的分布有集中与分散之别；部分地图在建筑上有响应，部分响应位于天空或地面。最后层 token 本身包含全局上下文，名义位置不等于独立像素区域，注意力不能证明价格因果。敏感度只覆盖残差分支，不能据此断言整个模型忽略了房屋、泳池或环境，也不能将难例自动归为脏数据。

## 成本记录

记录总墙钟为 31557.37 秒。第三折有一轮异常长间隔 26742.76 秒，而该折中位单轮约 38.67 秒；因此总墙钟不能当作常态 GPU 计算成本。重训单轮中位数约 76.75 秒，主机内存探测曾显示可用内存约 0.25–0.34 GiB。随机读取 12.5 GiB patch 缓存存在资源压力，但单次探测不足以隔离暂停、调度和 I/O 的各自影响。见 [resource_probe.json](resource_probe.json) 及各折训练曲线。
