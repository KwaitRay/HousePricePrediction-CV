# SigLIP2 SO400M NaFlex：576 patch 冻结特征

训练侧分组 CV 选择 gamma=1、alpha=0.1，OOF MSE **64475.12946**。固定验证 MSE **63086.48141**，MAE **181.28437**，高价组 MSE **273365.78196**。

相对固定方形 SigLIP2 的 62189.37，单模型验证总体误差略差；高价组较原 285929.78 有所改善。保留原图宽高比并不保证单模型更准，需要通过训练侧融合检查互补性。编码器和预处理均采用官方 NaFlex 实现，固定 576 patch 预算，价格超参数只用训练分区选择。

进入预先登记的新编码器联合融合后，训练侧学习到约 **36.62%** 权重。联合融合验证 MSE 为 **57982.72726**；这不是本单模型的成绩，也不是 Kaggle 公榜成绩。详见[联合融合报告](../../../15_fixed_ensembles/encoder_family_oof_fusion/20261014T012302Z_b883fad1/实验报告.md)。
