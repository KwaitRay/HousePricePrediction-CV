# DINOv2-L：CLS 与 patch mean 冻结特征对照

训练侧分组 CV 选择 gamma=1、alpha=1；OOF MSE **87066.09758**。固定开发验证 MSE **80787.02892**，MAE **206.89005**，高价组 MSE **411908.83061**，明显弱于当前 SigLIP2 单视图核的 62189.37。

使用官方通用视觉骨干，仅输入提供的图片，采用官方短边 256、中心裁剪 224 预处理。CLS 与 patch mean 分别归一化后拼接，输出 2048 维；价格核回归超参数只用训练侧完整未加权 MSE 选择。模型、预训练目标、读出与官方预处理均与 SigLIP2 不同，此结果不是单独的结构或裁剪消融。

保留为新编码器联合融合的预先登记候选，由训练 OOF 决定实际权重；单模型较差不证明融合必然无益，也不能据此断言 DINOv3 无效。新增 DINO 家族扩容暂置于 NaFlex、PE-Core 与 SigLIP2 Giant 验证之后。

配置与全部训练侧候选见 [registration.json](registration.json)、[training_cv.csv](training_cv.csv)。本模型没有公榜反馈；未使用测试标签、MLLM 或额外 SoCal 数据。
