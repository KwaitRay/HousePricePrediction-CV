# 预处理阶段实验报告

更新：2026年10月2日。六项单因素初筛、入围方案三次随机训练复核、一次组合验证均已完成。当前没有训练任务运行。

## 一、结论与推荐方案

**当前推荐：将图片直接拉伸至224×224，沿用固定数值归一化，不添加滤波。** 这是现有证据和预登记规则下的阶段选择，并非已经证明的普遍最优方案。

直接拉伸在三次随机训练中有两次超过同种子基线，平均均方误差降低0.50%，平均绝对误差也最低。频域滤波虽然取得第一次初筛的最好成绩，但另外两次均未超过相应基线；三次平均成绩略逊于拉伸。频域加拉伸的组合没有超过任何一个单项，暂不选取，也暂不追加组合训练。

推荐仍有代价：拉伸的三次平均高价尾部误差比基线高约2.99%，整体收益较小，逐种子的配对区间均跨零。若后续明确以高价房表现为首要目标，应重新登记评价重点，而不能沿用整体误差排名宣布同一个赢家。

## 二、研究问题与公平比较方式

本阶段回答：在同一网络和训练策略下，改变图像输入方式能否提升预测？基础对照保留方向与颜色处理、等比缩放补边至224×224、张量转换、固定均值和标准差均为0.5的数值归一化。因此对照是“无额外预处理”，不是完全不处理原图。

| 固定条件 | 本阶段设置 |
| --- | --- |
| 数据 | 6399张训练、1601张验证；重复图片按组划分；测试集不参与方案选择 |
| 网络 | 完整AlexNet，从随机初始化训练，不使用预训练权重、随机增强 |
| 训练 | AdamW，学习率0.0001，权重衰减0.0001；每批4张、累积8批；随机失活概率0.5；单精度 |
| 停止与权重 | 最多60轮、至少40轮；连续15轮未达到0.1%有效改善时允许停止；恢复最低验证误差权重 |
| 随机性 | 初筛种子2026；入围后追加2027、2028；划分不变，同种子配对初始化与采样规则一致 |
| 主要指标 | 原价格尺度的均方误差，越小越好，单位为千美元的平方 |
| 辅助指标 | 平均绝对误差，单位为千美元；高价尾部均方误差，针对价格严格大于1300千美元的159张验证图 |

每组只改变登记因素；组合组明确同时启用滤波与拉伸，并分别与两个单项比较。不同方案实际训练轮数可以不同，停止规则一致。早期旧版固定60轮运行和中断运行不混入本报告的正式排名。

初筛后，将最佳候选和距其均方误差不超过1%的候选送入复核，因此入围的是频域滤波与直接拉伸。最终要求平均均方误差低于基线且至少三次中的两次改善。只做一次的其他候选是证据不足、优先级降低，不能判定普遍无效。

### 实验一：直接拉伸

**依据与改动。** 检验补边是否浪费输入面积。仅将等比补边替换为直接拉伸，保留整张图，但改变宽高比例。

**结果与定位。** 初筛整体误差降低2.17%。低价组的均方误差从171715.68降至106827.99，中价组仅小幅改善，高价组却增加52402.15；低价改善抵消了高价退步。补边比例最高组只改善416.70，改善并未随补边比例单调增加，不能简单断言“去掉黑边就是全部原因”。最佳权重训练误差仅8020.86，而验证误差128268.67，说明很强的训练拟合没有等量转化为泛化收益；对照最佳轮次为6、候选为40，训练拟合差异也受到检查点位置影响。

**机制判断与建议。** 去补边、改变主体尺度和比例形变同时发生，尚未分别识别其贡献。现有证据支持它改变了误差分布，不足以证明某种视觉机制。三种子复核后按规则保留；后续训练调优优先关注泛化差距，并持续监测高价房低估，不再盲目叠加预处理。

### 实验二：中心裁剪

**依据与改动。** 检验放大中心主体能否减少外围干扰。短边缩放至256后裁取中心224区域，其他设置不变。

**结果与定位。** 初筛整体改善0.86%，高价尾部几乎不变。低价组改善39509.06，中价组退步6653.23，高价组退步13866.09。纵向图组也没有改善。训练误差8431.12、验证129985.99，仍有很大泛化差距。

**机制判断与建议。** 主体放大与外围信息丢失可能同时存在，但目前只定位到收益主要集中在低价组，未证明庭院或房屋边缘被裁去是具体失败原因。未进入复核范围，暂不选取；若未来重新研究，应先检查失败图片的裁剪区域，再单独试验更轻裁剪，不能与拉伸叠加。

### 实验三：提高输入分辨率

**依据与改动。** 检验224输入是否丢失有效细节。仅把等比补边输出提高到320×320，回归头和其他设置不变。

**结果与定位。** 整体改善1.61%，耗时却由27.44增至48.89分钟，约增加78%。低价、中价组分别改善42429.69和9124.00，但高价组退步58811.97，高价尾部退步88027.79。原图长边小于320的55张也出现改善，因此无法将收益全部解释为恢复了更多原始细节。

**机制判断与建议。** 改分辨率也改变特征采样和主体尺度；现有证据不足以将其分离。成本较高且未达到初筛入围线，保留224输入。以后只有发现具体小结构遗漏且预算允许时，再做独立分辨率研究。

### 实验四：训练侧通道标准化

**依据与改动。** 检验数据自身的颜色数值尺度是否更适合优化。仅用训练侧计算通道均值和标准差，替代固定0.5归一化，不使用验证统计。

**结果与定位。** 整体仅改善0.70%。非尾部误差下降13925.59，但高价尾部误差上升117066.21，是六项中尾部退步最大的一项；高亮度、低亮度两组也都退步。平均绝对误差下降，并不意味着大误差样本改善。

**机制判断与建议。** 数值变换改变优化路径，却不增加图像信息。数据专属统计没有展现明确的整体优势，也未解决亮度两端问题。暂不选取，保留固定归一化；若重新研究，应单独核验数值尺度、补边值和学习率的关系，不同时更改训练条件后声称是归一化收益。

### 实验五：空间高斯低通

**依据与改动。** 检验平滑局部高频变化是否有帮助。原图缩放前加入5×5高斯滤波，标准差0.5，采用反射边界。

**结果与定位。** 整体改善1.31%，高价尾部退步67861.43。清晰度指标较低组改善8860.18，较高组反而小幅退步153.06；低价、中价收益与高价损失并存。耗时35.35分钟，高于基础对照。

**机制判断与建议。** 数据支持平滑对不同图像组作用不同；该清晰度指标同时受噪声、边缘和纹理影响，不能直接当作噪声标签。暂不选取，也不与频域低通重复叠加。未来若噪声确为主要问题，应先用受控噪声扰动验证敏感性，再考虑更有针对性的处理。

### 实验六：频域高斯低通

**依据与改动。** 检验另一种确定性高频抑制方式。原图边缘反射扩展10%，逐颜色通道滤波，频率尺度为每像素0.25周期，再裁回原范围、缩放补边。它与空间滤波的核及边界设置不完全相同，不能据此比较两个处理域的普遍优劣。

**结果与定位。** 初筛最佳，整体改善2.67%；按原图分组重采样的均方误差变化区间为−6914.25至−530.11，在该次训练下支持改善。低价组改善48993.41，中价组改善5185.68，高价组退步46741.64；三个清晰度分组均有改善，但低清晰度组最多。高价尾部平均低估由基线762.88扩大到795.28千美元，提示整体提升伴随高价预测变差。样本192的真实价格282.99，预测由1233.77降至1092.89，仍明显高估；样本2138的真实价格1995，预测由589.28进一步降至373.39，显著增加平方误差。这些是预测证据，不是对图片内容的因果解释。

**机制判断与建议。** 抑制无关高频是可能机制，但也可能损失价格相关纹理，且训练随机性影响结论。三种子中只有一次超过基线，说明单次区间不能替代训练重复性验证。因此不作为最终首选，保留为备选，不因初筛最好而覆盖复核结果。缓存可解决速度问题，但不能解决预测稳定性问题。

## 四、多种子复核：为何最终不直接选频域滤波

| 方案 | 种子2026 | 种子2027 | 种子2028 | 三次平均均方误差±样本标准差 | 相对基线改善次数 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 基础对照 | 131108.78 | 128134.17 | 126004.11 | 128415.68±2563.95 | — |
| 直接拉伸 | 128268.67 | 127296.48 | 127758.11 | **127774.42±486.30** | **2／3** |
| 频域滤波 | 127610.87 | 128379.69 | 127668.58 | 127886.38±428.19 | 1／3 |

| 方案 | 平均整体改善 | 平均绝对误差 | 平均高价尾部误差 | 平均运行分钟 |
| --- | ---: | ---: | ---: | ---: |
| 基础对照 | — | 269.40 | 659848.02 | 29.06 |
| 直接拉伸 | 0.50% | **264.52** | 679580.17 | 36.58 |
| 频域滤波 | 0.41% | 267.31 | 676571.41 | 25.50 |

拉伸与频域的平均均方误差仅相差111.96，约为频域成绩的0.09%，不能夸大差距。频域的候选成绩标准差更小，但“自身波动小”不等于“相对基线稳定改善”：同种子基线也在变化。拉伸因平均误差最低、平均绝对误差更低且符合两次改善规则，被选作下一阶段输入。两者都没有解决高价房低估问题。

上述标准差来自三次独立训练的指标，不是集成预测的成绩，也不是差值的置信区间。划分固定、多次使用验证集做选择，因此这些是开发结果，不能当作独立测试泛化证明。

## 五、组合验证：频域滤波加直接拉伸

**依据与控制。** 两项操作分别作用于高频成分和几何变换，在实现上兼容，因此检验是否有叠加收益。固定先对原图频域滤波，再直接拉伸，不调整滤波强度或训练参数。单独生成最终拉伸张量缓存，不能把旧补边缓存二次拉伸冒充此组。

| 种子2026方案 | 均方误差 | 平均绝对误差 | 高价尾部误差 |
| --- | ---: | ---: | ---: |
| 基础对照 | 131108.78 | 278.56 | 641434.87 |
| 仅频域 | **127610.87** | 261.64 | 706342.75 |
| 仅拉伸 | 128268.67 | **259.99** | 700139.56 |
| 频域加拉伸 | 128889.84 | 266.13 | 656864.20 |

**结果。** 组合比基线改善1.69%，但比仅频域差1.00%、比仅拉伸差0.48%。训练60轮，最佳也在第60轮，耗时36.53分钟；它在后期恢复，因此没有在第40轮停止，也不能认定已经完全收敛。本阶段不为它单独延长预算。

**差异定位。** 组合的非尾部误差为70673.53，高于仅频域的63797.85和仅拉伸的65212.17；高价尾部反而优于两个单项。以仅频域为参照：1442张非尾部图片退步对全体验证均方误差贡献约+6192.83，159张尾部图片改善贡献约−4913.86，合计+1278.97。这解释了“高价改善却整体退步”的算术来源。相对基础对照，组合低价组改善48318.64，中价组退步5722.75，高价组退步19942.02。

**机制边界。** 在均方误差加性尺度上，组合交互量为+4119.08，体现这次训练中的收益抵消，而非互相增强。训练误差4448.96、验证128889.84，表明训练拟合非常充分、泛化差距较大；也需注意各方案最佳轮次不同。滤波后的频谱经非等比缩放发生变化、细节与形状线索相互影响，都是待验证解释，尚不能断言二者存在已证实的算法冲突。

**是否选取与解决建议。** 暂不选取、不追加种子。组合相对频域的配对差值区间为−3687.26至6495.66，相对拉伸为−3981.13至5743.77，均跨零；单种子不能证明组合必然更差，但它没有展现值得优先追加算力的整体收益。若后续专门研究尾部预测，可重新登记组合复核；若延长训练预算，必须同步补相同预算的对照。当前更合理的下一步是保留拉伸，进入独立训练调优阶段。

## 六、工程优化与历史记录如何解释

持久数据加载器和固定小批量诊断缓存减少重复进程启动；统一早停减少部分无收益轮次。正式排名仅使用共同新版协议，旧固定轮数实验是历史证据。

频域滤波原来在每次读取原图时重复计算，数据等待包含在训练计时内，不能将全部耗时归咎于显卡训练。频域补边缓存一次性构建9.34分钟，组合拉伸缓存8.18分钟，各约4.49吉字节；复用时无需重新滤波。频域已核对的对应稳定轮次由约481.66秒降至35.98秒，减少约92.53%，这是这些对应轮次的实测结果，不是所有训练的统一加速比。

缓存验证包含8000张张量写入后逐项读回核验、64张独立重算、两轮小规模显卡训练权重及预测完全一致；补边频域的正式前三轮也与未缓存记录一致。一次性构建、启动完整性校验和训练计时分别记录。中断及用户授权重启的未完成实验保留，但不算独立种子或正式成绩。

## 七、阶段决策与下一步

| 项目 | 决策 | 原因及后续动作 |
| --- | --- | --- |
| 直接拉伸 | **推荐选取** | 三种子均值最低、符合两次改善规则；固定224输入和当前归一化，继续监测尾部 |
| 频域滤波 | 保留备选 | 初筛最好但复核仅一次改善；已有缓存可支持必要的后续针对性研究 |
| 中心裁剪、320输入、通道标准化、空间低通 | 暂不选取 | 未进入既定复核范围；各有信息损失、成本或尾部退步问题，不宣称普遍无效 |
| 频域加拉伸 | 暂不选取、停止扩展 | 单种子未超过单项；尾部收益被非尾部损失抵消 |
| 训练调优 | 下一阶段单独开展 | 先冻结所选输入，每次只调整登记训练因素；不把调参收益算作预处理收益 |

需要优先处理的是低价房高估、高价房低估及训练验证差距。后续可按设计先比较学习率，再研究正则化与停止策略；本报告只提出建议，没有启动调优任务。验证协议不改变，测试集仍不参与决策。
