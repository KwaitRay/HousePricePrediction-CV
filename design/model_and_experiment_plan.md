## 1. 任务、数据和课程范围

### 1.1 预测什么，什么信息可用

输入一张房屋图片，输出连续售价。图片提供建筑外观、庭院、材质和周围环境等线索；地段、真实面积、室内条件及交易因素往往不可见，因此视觉相似不保证价格接近。核心研究是：改善图像中价格相关信息的表示和读出，能否降低原价回归误差，并减少低价高估、高价低估？

| 数据 | 数量与格式 | 用途 |
| --- | --- | --- |
| 提供的训练图与 `train.csv` | 8000 张，`imageid,price` | 固定训练/验证、训练侧 CV、最终全量重拟合 |
| 提供的测试图与 `test.csv` | 3000 张，无售价 | 完整性检查和冻结方案后的最终推理 |
| `sample_solution.csv` | 3000 行格式示例 | 参考列名和顺序，不作为测试真值 |

`price` 原始单位是千美元；例如 549.9 表示 549900 美元。训练可将目标再除以 1000，预测须乘回；Kaggle CSV 保持千美元，不能因网页示例歧义改变单位。训练价格范围 195–2000，中位数约 639.9，分布右偏。

### 1.2 方法边界

依据本地课程 PDF 第 2 页（外层文件 `Final_Assignment/COMP90086_2026_Project.pdf`）：允许通用预训练特征，禁止在本任务/提供数据集上训练过的预训练模型、额外原始 SoCal 图片或元数据，以及预训练多模态大语言模型。这里只使用提供的图片和标签，具体视觉权重仍需登记来源与版本。

当前课程路线为通用视觉编码器 + 本组拟合的回归器/价格监督读出。Qwen3-VL-Embedding 等 MLLM 衍生模型仅作用户授权的独立本地研究，不加入课程 CSV、课程融合或 50000 目标统计；输出 embedding 而非文本不改变其来源边界。

文件名、编号、顺序、训练测试图片匹配和人工测试标签不作为预测特征；不复制匹配训练图的价格到测试图。测试图片不用于预训练、伪标签、统计拟合、校准或选参。对失败图片不自动删图、改价或认定脏数据。

## 2. 统一评价与实验完整性

### 2.1 冻结划分与训练侧拟合

保持 **6399 train / 1601 validation**，划分种子 2026。完全重复图片按组，已复核的 `1078.jpg` / `3568.jpg` 近重复也同组；`738.jpg` / `861.jpg` 图片相同但标签不同，保留原记录并同组，不平均售价。分组不跨两侧，8000 个编号恰好出现一次；不宣称已经识别所有物业身份。

组按售价中位数和稳定组标识排序，最多 10 层抽取约 20% 验证组，实际行比例允许随组大小变化。固定索引见[共享划分说明](../data_split/README.md)，机器本地划分路径由 `local_paths.json` 指定。训练 CV 使用分组三折，每折重新拟合词典、标准化器、监督距离或回归头；确定性冻结图像特征可以在来源与预处理一致时缓存复用。

已有 EDA 看过全部训练标签，验证集亦反复用于开发；多种子和 bootstrap 不能消除此选择偏差。选定基础参数的 OOF 及仅对元模型交叉拟合的分数，不标成完整嵌套、无偏或独立测试成绩。

### 2.2 指标和切片

| 指标 | 定义与用途 |
| --- | --- |
| 原价完整验证 MSE | 千美元尺度误差平方的均值，唯一主指标；全部 1601 条等权 |
| MAE | 千美元尺度绝对误差均值，解释平均偏差金额 |
| 高价尾部 MSE | 固定训练侧阈值 >1300，验证 n=159；报告样本数与总体取舍 |
| 有符号偏差及低价高估 | `mean(pred−truth)`；必要时另报正向过估均值及比例 |

价格切片统一使用 ≤300、300–700、700–1300、>1300。训练类别索引的一层标签为低价 ≤300、中价 300–1300、高价 >1300；不能将它的中价/高价名称与四档切片混用。绝对误差档为 ≤100、100–300、300–500、500–1000、>1000，单位千美元。视觉类别可重叠，未知单列；比较类别时同时报告真实价格分布，避免把价位构成误当视觉机制。

先按 imageid 对齐预测和真值，再算指标；缺失、重复或非有限输出使该次评价无效，不能删除后报分。统一恢复单位并设非负下限，不设训练最高价上限；保存未截断输出和非正数量。随机神经网络训练损失使用未截断输出。过采样、加权损失和不同目标空间仅改变训练，主验证仍是原始等权 MSE。

### 2.3 控制变量、复核和晋级

模块消融只改变登记因素，公开必要的容量、接口和计算量变化；各架构独立调优后的比较属于完整方法比较，不能把收益全部归于架构。相同最大轮数不等于相同训练步数或成本，梯度累积也不等于更大的对比 batch。

| 方法类型 | 筛选与晋级规则 |
| --- | --- |
| 从零训练/随机神经网络干预 | 2026 初筛，完整性通过且优于直接对照才追加 2027/2028；采用须三种子平均 MSE 下降且至少 2/3 同种子改善 |
| 冻结特征 Ridge/RBF/监督距离 | 小规模训练分组 CV 选参数，再评固定完整验证；报告搜索全部候选，不能把确定性方法机械重复三次当新证据 |
| 学习融合权重 | 训练 OOF 拟合非负、和为 1 的权重；元模型分组 CV 相对预先冻结基线改善至少 1%、至少 2/3 折获胜且完整验证改善后才导出 |

新增融合应明确以当前 56549.27 方案还是其他事先登记方案为基线，不能默认沿用更旧基线降低门槛。小于门槛的收益仍保存，但不事后改规则使其晋级。低价 MSE 恶化 >5% 或平均正向过估增加 >10% 作为训练干预的取舍警戒；这些是工程选择规则，不是显著性阈值。

神经网络每轮保存严格最低验证 MSE 权重，同分取较早轮；停止计数只在相对改善 >0.1% 时清零。必要时按 group_id 做 1000 次配对 bootstrap（seed 2026），报告候选减对照的 MSE 差及 95% 区间，并区分训练种子波动与固定样本不确定性。开发验证、公榜、训练拟合、扰动诊断分别展示。

## 3. 研究逻辑：证据决定下一项改动

```mermaid
flowchart TD
    A[数据完整性与分组划分] --> B[均价与传统特征参照]
    B --> C[从零训练：输入、优化、增强、结构与读出]
    C --> D[CLIP 证明通用视觉表示能明显改善预测]
    D --> E[冻结编码器 + 训练侧选择 Ridge/RBF]
    E --> F[NaFlex、PE、Giant 与保留全图的多视图]
    F --> G[训练 OOF 融合与冻结验证]
    G --> H[全量重拟合、独立导出审计、公榜反馈]
    G --> I[训练侧价位 × 场景与残差诊断]
    I --> J[监督距离、细节视图、新视觉家族或有证据的数据干预]
    J --> G
```

| 问题与证据 | 研究假设 | 合适的下一项对照 | 判断边界 |
| --- | --- | --- | --- |
| 从零小头均值 122334.22，CLIP Ridge 91820.73 | 表示学习能力与数据规模限制了当前小网络 | 冻结通用 encoder，用同一划分的浅层回归器比较 | 改变预训练、容量和架构，不是单一模块因果实验 |
| 强语义编码器仍向中价收缩 | 视觉相似性未充分对齐连续价格 | 训练折内监督 PLS 距离、价格辅助对比 | 同价外观不同是难正，异价外观相近是难负；无法看到的价格因素可能诱发记忆 |
| 部分主体小、局部信息可能随缩放损失 | 保留全图同时读取细节可能有帮助 | 固定全图+局部、letterbox 或独立分辨率对照 | 不能任意裁背景；提高输入大小不能补出原图不存在的细节 |
| 相近单模型仍可能误差互补 | 不同预训练目标/几何处理提供不同预测偏好 | 训练 OOF 的增量融合 | 残差相关低不保证融合获益；权重不是对象重要性 |
| 高价训练地面外观失败多，覆盖尚不完整 | 场景×价位覆盖可能影响学习 | 先补低价标签、训练 OOF 切片，再温和重采样/权重 | 高价本身不等于困难；增强不增加独立房屋；原始等权验证不变 |
| 多模型共同失败、近邻价格差大 | 图外信息或当前模型能力可能限制结果 | 失败/成功对照、近邻与敏感性审计 | 不自动当脏数据，不由共同失败估计已证实的不可约误差下界 |

当前不能认定数据配比、泳池、曝光或注意力错位是主因。先定位误差来自哪些价位与场景，再研究对应因素；训练干预需要诊断触发，不能将多个变换同时叠加后归因于数据质量。

### 6.4 P3：新视觉目标和读出候选

以下均为待检验方向，通用检索/分类成绩不能直接证明房价 MSE 更低。

| 候选 | 任务假设与第一项实验 | 决策约束与来源 |
| --- | --- | --- |
| NaFlex 更大 patch 预算 | 保留宽高比和细节，独立增加 token 预算 | 先资源预检，与已完成 576 patches 直接对照；[官方接口](https://huggingface.co/docs/transformers/model_doc/siglip2) |
| PE-L 中间层 / PE-Spatial | 空间与局部特征可能补充最终语义输出；预定一个层/池化方式 | 全图参照不变，不同时更换骨干与读出；[官方实现](https://github.com/facebookresearch/perception_models/blob/main/apps/pe/README.md) |
| DINOv3 B/16 或 L/16 通用 web 权重 | 自监督密集视觉表示，先 CLS / patch mean / 拼接 | 三种读出事前固定；DINOv2 较弱不直接否定它；[官方来源](https://github.com/facebookresearch/dinov3) |
| AIMv2-Large 视觉编码器 | 不同预训练目标可能提供互补性 | 仅发布的通用视觉骨干，冻结 Ridge/RBF；[模型来源](https://huggingface.co/apple/aimv2-large-patch14-224) |
| EVA-CLIP / EVA02-CLIP L 级 | CLIP 家族配方补充 | 在前面候选后按预算决定，不默认巨型模型；[官方来源](https://github.com/baaivision/EVA/tree/master/EVA-CLIP) |

一个实验只新增一个编码器、输入方案或读出因素。单模型稍弱仍可检验 OOF 融合互补性，但不根据验证或公榜遍历很多层/窗口/权重挑最低。模型 revision、预处理、精度、特征维度和代码版本共同定义缓存身份。

### 6.5 P4：诊断触发的数据干预与对比训练

| 分支 | 启动条件 | 唯一改动与对照 |
| --- | --- | --- |
| 主体/细节 | 同价位、同场景审计支持小主体/缩放丢失线索 | 保留全图的固定局部特征或预测融合；必要时参数量匹配对照，不逐图选有利裁剪 |
| 曝光 | 原关联门槛至少 30 例/组、MSE 比 >1.2，且新的训练侧留组诊断支持 | 温和亮度 p=0.5、倍率 0.9–1.1；不同时锐化、去噪或变对比度 |
| 场景×价位覆盖 | 可靠补标/训练留组诊断确认不足，未知独立处理 | 温和重采样或加权损失分别研究，不同时改变采样与损失 |
| 价格对比 | 冻结强特征浅层读出仍不能保留可见价格差异 | λ=0、简单对比、难负、难正逐项消融；先头部，再据证据考虑局部解冻 |
| 信息不足候选 | 多模型 OOF 共同失败且视觉近邻价格分散 | 固定失败与成功对照分析，不删图、不改价 |

同价而外观不同是难正，异价而外观相似是难负。价格接近并不要求整幅图像所有信息都一致，辅助约束须温和，不默认所有 batch 其他图片都是负样本。历史 C0–C3 的完整参数保存在[协议补充](实验协议补充.md)，属于未整体执行的从零路线设计；不能将其当作已有冻结 CLIP/SigLIP 头实验的确切设置或当前自动队列。

[Qwen3-VL-Embedding-2B](https://huggingface.co/Qwen/Qwen3-VL-Embedding-2B)计划为固定图片+instruction → 冻结归一化向量 → 训练标签拟合 Ridge/RBF；尚未启动。它使用语言模型路径，课程路线排除。已有 Qwen3.5-2B 零样本直接估价约 109500.16，不能替代 embedding 的监督回归对照。

## 7. 从实验登记到最终输出

每项新实验登记“证据 → 假设 → 直接对照 → 唯一变化 → 生效参数/搜索范围 → 评价与晋级 → 成本 → 结果与下一步”。先少量训练图检查正确性和资源，再开始完整实验；预检是工程验收，不是预测效果证据。相同配置与数据已验证的运行可复用，不重跑来制造额外证据。

| 产物 | 必须保存 |
| --- | --- |
| 来源和完整性 | 数据/划分/标签/配对/模型 revision、源码及预处理指纹，环境、精度、设备 |
| 拟合与预测 | 全部 CV 候选、折内学习对象、回归头/权重、逐图预测、停止与失败原因 |
| 比较与解释 | 完整 MSE/MAE/尾部、切片 n/偏差、成本、采用/未采用结论 |
| 归因审计 | 固定样本、层与显示范围；价格输出的梯度/遮挡或适用的 Grad-CAM |

注意力和敏感图只说明响应，不证明泳池、面积或背景的因果贡献；辅助对比投影热图不替代价格输出解释。近邻、PCA 和二维嵌入只作探索，PCA 训练拟合。增强、扰动、重复视图不增加置信区间的独立房屋数量。真正新视角合成需要深度/位姿等信息，本轮不借二维变换声称恢复 3D 面积。

公开聚合和协议写到 `output/experiment_record/`；权重、原图、逐图私有证据和缓存在 `.local/`。每次新 run，不覆盖历史失败或注册哈希。当前脚本、运行资源和准确路径由[接续文档](后续实验与新窗口接续.md)维护，主设计不重复动态 PID 或长 SHA。

方案冻结后在全部 8000 标签图重拟合所有训练统计和回归头，保持 CV 选定参数及融合权重；神经网络全量训练时长从最终开发方案事前确定，例如三种子最佳轮次中位数。测试时固定处理器、关闭随机增强/失活，仅推理，不再拟合任何统计量。

最终 CSV 按 test.csv 顺序输出 **3000 行 `imageid,price`**、无索引、唯一且覆盖完整、有限非负。保留 CSV SHA、验证回放、缓存/原图校验与独立价格回放，公榜反馈绑定具体 CSV。全量训练误差不是验证成绩，公榜不是最终私榜；预测区间若未校准，不能称为置信区间。
